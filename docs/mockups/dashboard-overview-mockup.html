Features available here

  • OpenWeather-powered conditions — current-conditions lookup per site lat/lng (manual override or Meraki ingest geo). Caches responses in-process to respect provider quota.
  • Severity threshold — the dashboard surfaces only sites where OpenWeather reports severe conditions (wind / rain / snow) above configured thresholds.
  • Cross-referenced with network impact — joins to the same Meraki + ThousandEyes data as the cards above, so a weather event always appears next to its ingest-derived network effect.
  • Privacy-safe — OpenWeather API key is stored in the server's encrypted credential vault; the browser only receives the processed weather payload, never the key.
